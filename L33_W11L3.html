When POST passes but the OS misbehaves, the fault is in firmware settings, the boot files, drivers, or the disk itself. The tools are: the firmware boot order, the OS recovery menu (safe mode), the event/system log, and the drive's own SMART report.

Example 1. 'No bootable device': boot order points at an empty port, or the SATA data cable is out. Firmware first, then the cable.

Example 2. PC boots, then crashes after a driver install: safe mode starts fine. Uninstall that driver.

Example 3. Slow, with freezes; SMART shows 'Reallocated sectors: 240' and 'Caution'. The drive is dying. Back up today; replace it.

Backups: 3 copies, 2 kinds of media, 1 somewhere else. A copy on the same disk is not a backup.
