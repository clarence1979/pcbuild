3 minStartwhole class

  • Host bench starts the server. Everyone joins. Teacher gives a 20-minute build or race challenge in-game.
  • Measurement roles: two benches keep ping running to the host in a second window; one watches the host's graphs.

4 minLearnteacher explains, you follow on screen

This is the reward and the experiment. While you play, the network carries a packet per player many times a second. Ping to the host should sit around 1 ms on a wired gigabit LAN. If the host's CPU hits 100% or its tick rate drops, everyone lags, no matter how good the cables are.

Example. Twenty players exploding TNT at once: the host's CPU spikes, ticks fall behind, and ping is still 1 ms. The network was never the problem; the server was.

Words

Latency
Round-trip time, shown by ping in ms; lower is better.
Bandwidth
How much data per second the link carries; a gigabit lab has far more than a game needs.
Tick
The server's update heartbeat (Minecraft: 20 per second).
Lag
What players feel when latency rises or the server falls behind its ticks.
