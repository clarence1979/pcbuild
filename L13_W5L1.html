14 minLearnteacher explains, you follow on screen

Two chips run the board. The CPU talks directly to RAM and to the x16 graphics slot, because those need the most speed. The chipset (under the small heatsink) handles the rest: USB, SATA, the network port, the M.2 slot and the x4 slot. Between CPU and chipset runs a fast link called DMI.

Example 1 — lanes. A graphics card in the x16 slot gets 16 lanes straight to the CPU. The NVMe drive gets 4 lanes via the chipset. Both are PCIe; the difference is width.

Example 2 — form factors. Standard sizes mean any ATX board fits any ATX case: same screw holes, same I/O cutout, same slot positions. Dell drew its own shape so the board only fits a Dell case. Cheaper for Dell; harder for us.

Example 3 — headers. A header is a row of pins. The front-panel header takes the power button; the fan header takes a fan; a USB header takes the front USB cable. On this Dell, the front USB is soldered on, so there is no USB header to find.

Words

Chipset
Intel Q270 here: links the CPU to USB, SATA, network and extra PCIe lanes.
PCIe lane
One two-way data path; x16 = 16 lanes.
ATX / micro-ATX / mini-ITX
Standard board sizes: 305×244, 244×244, 170×170 mm.
I/O shield
The metal plate around the rear ports on a standard case.
