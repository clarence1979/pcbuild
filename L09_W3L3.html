10 minLearnteacher explains, you follow on screen

RAM faults are sneaky. A stick can be mostly fine but have a few bad cells. The PC works until a program lands on those cells, then crashes for 'no reason'. A memory test writes patterns to every cell and reads them back, over and over.

Example 1. A laptop blue-screens once a day with a different error each time. MemTest finds 14 errors in pass 1. New RAM, problem gone.

Example 2. A desktop will not POST and the Dell light blinks 2, then 3 (or 3, then 3). Nothing to test yet: that pattern means the board cannot see any working memory. Reseat, then try one stick at a time.

Example 3. Memory test passes but the PC still crashes. The fault is somewhere else: overheating, storage, drivers. A pass tells you what it is not.

Words

MemTest86
A program that boots from USB and writes patterns to every byte of RAM to find errors.
Blue screen (BSOD)
Windows crash screen; random ones often point to RAM.
Diagnostic LED
The Dell power button blinks a two-number amber pattern to say what failed.
