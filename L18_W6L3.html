Today is rehearsal. Every plug goes on, every route is chosen, nothing is powered. In Week 9 you will do this for real inside the frame, fast, because you have already done it once.

Example 1. The adapter: ATX 24-pin goes into the adapter's socket; the adapter's 6-pin goes into the Dell board. The 24-pin latch must click. The 6-pin is keyed and clicks too.

Example 2. The 4+4 CPU plug: you only need one half (4 pins) for this board. The halves are keyed; the shape of the pin housings matches the socket.

Example 3. Route cables so nothing crosses the CPU fan and the PCIe slot stays clear for the graphics card. Tie off the unused leads; a loose SATA plug touching the board can short it.

Words

Adapter
A short lead that changes one plug type into another, here 24-pin ATX to Dell 6-pin.
Keyed
Shaped so it fits one way only.
Dry run
Doing the job with no power so mistakes cost nothing.
Strain relief
Routing so the cable's weight does not pull on the plug.
