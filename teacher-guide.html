ReBuild Lab — teacher guide

Lesson answers, kit, planted faults, address plan and curriculum notes. Not for student distribution.

How the lesson pages work

Every page is a single standalone HTML file with no external dependencies; copy the folder to each bench PC or host it on the intranet. The sticky header runs a 45-minute timer with a segmented timeline (Start / Learn / Do / Check / Pack down). Step checklists persist per browser via localStorage. Quizzes give instant feedback. The right-hand "Open the printable worksheet" button opens the embedded A4 PDF in a new tab (and "download the PDF" saves it); the PDF is base64 inside the file, so it works offline from a file:// URL. Figures are inline SVG with CSS/SMIL animation and respect prefers-reduced-motion.

Driver/Navigator roles swap every lesson. The Navigator reads steps aloud and owns the pre-power check; you say "go" before any mains lead is connected.

Operating system note

The OptiPlex 7050's 7th-generation Intel CPU is not on Microsoft's Windows 11 supported-processor list and Windows 10 reached end of support in October 2025, so the lessons default to Linux Mint for the fresh install (Week 11). Windows steps are given in parallel wherever a command differs. If the school prefers Windows 11 via an unsupported-hardware install, the hardware lessons are unchanged; the Week 16 Python code runs on either.

Safety summary

  • Unplug, press the button, strap on, open — every lesson, same order. Strap clipped to bare metal.
  • Never open a PSU. The paperclip start is a teacher demonstration only; students use the PSU tester or Dell BIST.
  • Isopropyl: small amounts, capped, no mains at the bench while in use.
  • Crimp tool and cutters: safety glasses, cut away from the hand.
  • Cabling: patch leads only, lab switch only. Fixed cabling is ACMA registered-cabler work.
  • Wireshark (Week 16) is teacher-run on the isolated lab network only.

Curriculum alignment

Victorian Curriculum 2.0, Digital Technologies Levels 9 and 10, Digital Systems and Security strand: students explain how hardware specifications affect performance and select appropriate hardware for particular tasks and workloads (Weeks 2–7, 17) and investigate how hardware and software manage, control and secure access to data in networked digital systems (Weeks 11–18). Processes and production skills are addressed through the iterative build, test and document cycle in every lesson. Where the school maps to the Australian Curriculum v9, the equivalent descriptors are AC9TDI10K01 (hardware and performance) and AC9TDI10K02/P14 (networked systems and security).

Industry framing: the course mirrors CompTIA A+ Core 1 domains 1–3 (hardware, networking, troubleshooting) at an introductory level; this is for context only and is not a certification course.
