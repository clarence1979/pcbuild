A host firewall is a list of rules checked against every incoming packet. The default on every modern OS is: outbound allowed, inbound blocked unless a rule says otherwise. That is why your server was unreachable until you added a rule. Good rules are narrow: one port, one protocol, one source range.

Example 1 — too wide. 'Allow all inbound' makes the chat work and also exposes file sharing, remote desktop and anything else listening. Wrong.

Example 2 — right size. 'Allow TCP 2323 inbound from 192.168.10.0/24'. The chat works; nothing else changes; a device from any other network is still blocked.

Example 3 — cleanup. At the end of the course, delete the rule. A door you forgot is a door someone else finds.

Words

Inbound rule
Permission for traffic arriving at this PC on a port.
Scope
Which source addresses a rule applies to; ours is 192.168.10.0/24 only.
Service
A program that listens and waits: a server.
Least privilege
Open only what is needed, to only who needs it, for only as long as needed.
