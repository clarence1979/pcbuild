A LAN game is the chat server with graphics. One PC hosts (listens on a port); the rest connect to its IP and port. Minecraft Java hosts on TCP 25565 by default; Luanti hosts on UDP 30000. The host PC needs an inbound rule for that port from the lab subnet. Everything else is the ladder you already know.

Example 1 — Minecraft Java. Host: Open to LAN from a single-player world (it prints a random port) or run the dedicated server (25565). Others: Multiplayer → Direct Connect → 192.168.10.14:25565.

Example 2 — Luanti. Host: Start Game → Host Server tick → port 30000. Others: Join Game → address 192.168.10.14, port 30000.

Example 3 — 'can't connect'. Ping the host: OK? Then telnet to 25565 (TCP): refused = server not running; timed out = firewall. For UDP you cannot telnet; check the host's rule and that the game says 'listening'.
