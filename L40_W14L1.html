14 minLearnteacher explains, you follow on screen

Computers address each other with 32-bit numbers. Humans cannot read 32 bits, so we chop them into four groups of eight (octets) and write each as a decimal 0–255. 192.168.10.11 is just a friendly way of writing 11000000.10101000.00001010.00001011.

Example 1 — converting. 192 = 128 + 64 = 11000000. 10 = 8 + 2 = 00001010. 255 = all eight bits on. 256 is impossible: eight bits only reach 255.

Example 2 — private ranges. Addresses starting 10., 172.16–31., or 192.168. are never used on the public internet. Every home and school reuses them. Our lab uses 192.168.10.0/24: 192.168.10.1 to .254 available, .11–.30 for benches.

Example 3 — special ones. 127.0.0.1 is 'myself' (loopback). x.x.x.0 is the network's name and x.x.x.255 is 'everyone' (broadcast); you never give those to a PC.

Words

IPv4 address
A 32-bit number written as four decimal octets, e.g. 192.168.10.11.
Octet
One of the four 8-bit groups; 0–255.
Private range
Addresses reserved for inside networks: 10.x.x.x, 172.16–31.x.x, 192.168.x.x.
Binary
Base 2: each digit is 0 or 1 and each place is worth double the one to its right.
