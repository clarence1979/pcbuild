Telnet works, but your own client is better: it listens for incoming lines in one thread and sends your typing in another. Then the class joins one server. With twenty clients, the server's single accept loop and twenty threads are all busy; watch its terminal.

import socket, threading, sys

SERVER = sys.argv[1] if len(sys.argv) > 1 else "192.168.10.11"
PORT = 2323

s = socket.socket(socket.AF_INET, socket.SOCK_STREAM)
s.connect((SERVER, PORT))

def listen():
    while True:
        data = s.recv(1024)
        if not data:
            print("Disconnected."); break
        print(data.decode(errors="ignore"), end="")

threading.Thread(target=listen, daemon=True).start()
while True:
    line = input()
    s.sendall((line + "\n").encode())
    if line.strip().lower() == "/quit":
        break

Example 1. Run with the server's IP as an argument: python chat_client.py 192.168.10.14. 'Name?' appears. Type your name, then chat.

Example 2. Someone types /quit: the server broadcasts '*** name left' and closes that socket. The other nineteen are untouched.

Example 3. The teacher captures port 2323 traffic with Wireshark and projects it. Every message is readable in the packet bytes. Nothing you type here is private. This is why real chat apps use TLS.
