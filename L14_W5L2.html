When you press the button, there is no Windows yet. A small program on a chip (the firmware) wakes the CPU, counts the RAM, finds the graphics output, checks the keyboard and then looks down its boot order for a drive or USB stick that contains an operating system. That whole process is the POST. Only after that does the OS load.

Example 1. You plug a MemTest USB in and nothing happens. The boot order still says 'SSD first'. Use F12 for a one-time choice, or move USB up in the order.

Example 2. The clock resets to 2017 every start and a message says 'Time-of-day not set'. The coin cell is flat. Replace it, set the clock, done.

Example 3. A Linux USB will not boot with Secure Boot on because its bootloader is not signed with a key the firmware trusts. Turn Secure Boot off for the install, or use a distribution that is signed.

Words

Firmware
Software stored on a chip on the board; runs before any disk is read.
UEFI
The modern firmware standard; BIOS is the old name people still use.
Boot order
The list of devices the firmware tries, in order, to find an OS.
Secure Boot
A UEFI check that only signed bootloaders run.
CMOS / NVRAM
Where settings and the clock are kept; the coin cell powers the clock.
