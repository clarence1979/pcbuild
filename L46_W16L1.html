A server is a loop: make a socket, bind it to a port, listen, then accept clients forever. Each accepted client gets its own socket and its own thread so twenty students can type at once. Every line a client sends is broadcast to everyone else. That is the whole program.

Example 1 — bind to 0.0.0.0. That means 'every network card on this PC'. Binding to 127.0.0.1 would only allow connections from the same PC.

Example 2 — port 2323, not 23. Real telnet lives on 23, but ports below 1024 need admin rights on Linux. 2323 is free and needs nothing special.

Example 3 — the firewall again. The server runs, a neighbour gets 'timed out'. Allow TCP 2323 in from 192.168.10.0/24 on the server PC. Only that port, only from the lab.

import socket, threading

HOST = "0.0.0.0"      # listen on every network card
PORT = 2323           # our chat door (telnet's usual door is 23, this avoids needing admin)
clients = {}          # socket -> name

def broadcast(text, sender=None):
    for c in list(clients):
        if c is not sender:
            try:
                c.sendall((text + "\r\n").encode())
            except OSError:
                clients.pop(c, None)

def handle(conn, addr):
    conn.sendall(b"Name? ")
    name = conn.recv(64).decode(errors="ignore").strip() or str(addr[0])
    clients[conn] = name
    broadcast(f"*** {name} joined from {addr[0]}")
    while True:
        data = conn.recv(1024)
        if not data:
            break
        line = data.decode(errors="ignore").strip()
        if line.lower() == "/quit":
            break
        if line:
            broadcast(f"<{name}> {line}", sender=conn)
    broadcast(f"*** {name} left")
    clients.pop(conn, None)
    conn.close()

srv = socket.socket(socket.AF_INET, socket.SOCK_STREAM)
srv.setsockopt(socket.SOL_SOCKET, socket.SO_REUSEADDR, 1)
srv.bind((HOST, PORT))
srv.listen()
print(f"Chat server listening on port {PORT}. Ctrl+C to stop.")
while True:
    conn, addr = srv.accept()
    threading.Thread(target=handle, args=(conn, addr), daemon=True).start()

Words

bind
Attach the socket to an address and port.
listen
Open the door: accept connections.
accept
Wait for a knock; returns a new socket for that one client.
recv / send
Read from and write to a connected socket.
Thread
A separate line of execution so one slow client does not block the others.
