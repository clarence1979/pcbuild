14 minLearnteacher explains, you follow on screen

Our lab stops at the switch. A real network adds three services. A router connects the LAN to other networks and is every PC's default gateway. DHCP (usually running on the router) hands out addresses so nobody types them. DNS turns names into addresses so nobody remembers numbers. NAT on the router lets all your private 192.168 addresses share the one public address your ISP gave you.

Example 1 — a web page at home. You type a name → DNS gives an IP → your PC sees it is not local → sends to the gateway → router NATs it out → reply comes back → router maps it back to your PC. Four services you never see.

Example 2 — why the lab is an island. No gateway means nothing can leave or arrive. That is deliberate: no updates mid-lesson, no outside traffic, no risk to the school network from student-built machines and open ports. The cybersecurity elective runs the same way.

Example 3 — adding internet properly. You would need a router with NAT, DHCP (or keep static), DNS forwarding, a firewall policy, and permission from the school's IT. That is a project, not a cable.

Words

Router
Forwards packets between networks using IP addresses; the default gateway.
DHCP
Hands out IP, mask, gateway and DNS automatically.
DNS
Turns names (school.vic.edu.au) into IP addresses.
NAT
Lets many private addresses share one public one.
WAN
Wide area network: the links between LANs, including the internet.
