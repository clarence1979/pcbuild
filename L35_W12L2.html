Sending data is like posting a letter inside an envelope inside a parcel. Each layer adds its own label and only reads its own label at the other end.

Example 1 — ping. Ping is an ICMP message at the Internet layer. It has IP addresses but no port, because it is not for any program; the OS answers it directly.

Example 2 — our chat. Your text (Application) → TCP adds ports 51000→2323 (Transport) → IP adds 192.168.10.11→.12 (Internet) → Ethernet adds the MACs (Link) → onto the cable. The server PC unwraps in reverse and hands the text to the program listening on 2323.

Example 3 — wrong layer, wrong fix. 'Minecraft can't connect' but ping works: the Link and Internet layers are fine. Look at the Transport/Application layers: port, firewall, is the game actually hosting?

Words

Frame
The Link-layer chunk: MAC to MAC, on one cable segment.
Packet
The Internet-layer chunk: IP to IP, across networks.
Port number
A number that says which program on the PC should get the data, e.g. 2323 for our chat.
Encapsulation
Wrapping data in headers, layer by layer.
Protocol
An agreed set of rules, e.g. TCP, IP, ICMP, Ethernet.
