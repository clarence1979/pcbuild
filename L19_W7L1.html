14 minLearnteacher explains, you follow on screen

A CPU has four big cores that do anything. A GPU has thousands of tiny cores that all do the same simple job at once: work out the colour of one pixel. A 1080p screen is two million pixels, sixty times a second. That is a parallel job, so a parallel chip wins.

Example 1 — the iGPU. The i5-7500 has Intel HD 630 built in. Fine for the desktop, video and old games. It uses system RAM as its VRAM, which is slow.

Example 2 — power. A PCIe slot can supply 75 W. A card with no power plug (GTX 1650 LP, RX 6400) lives on that and will run on the Dell PSU. A card with an 8-pin plug needs the ATX PSU, so it waits for Week 9.

Example 3 — size. A full-height card is 112 mm tall; the SFF case fits only 'low profile' (69 mm). Length matters too: the open frame has no limit, the SFF has about 170 mm.

Words

GPU
Graphics processing unit: thousands of small cores for drawing pixels in parallel.
VRAM
The GPU's own memory for textures and frames.
iGPU / dGPU
Integrated (inside the CPU) vs dedicated (a card).
Low profile
A short-bracket card that fits a slim case like the SFF.
TBP / TGP
The card's peak power in watts.
