12 minLearnteacher explains, you follow on screen

An IP address gets you to the right PC. A port gets you to the right program on it. Web servers listen on 80 and 443, Minecraft on 25565, our chat on 2323. Telnet is the simplest client there is: it opens a TCP connection to an IP and port and sends whatever you type.

Example 1. telnet 192.168.10.1 2323 → 'Connected'. Type 'hello' → it appears on the teacher's screen. The teacher types back → it appears on yours. That is a raw TCP socket, with nothing in between.

Example 2. telnet 192.168.10.1 2324 → 'Connection refused'. The PC is there (Internet layer fine) but no program is on door 2324 (Transport layer: no listener).

Example 3. telnet 192.168.10.99 2323 → hangs, then 'timed out'. Nobody answered at all: wrong IP, or a firewall silently dropping. Different error, different layer.

Words

Port
A 16-bit number (0–65535) that picks which program on a PC gets the data.
Socket
One end of a connection: IP address + port.
Listening
A program waiting on a port for connections.
Telnet
A very old, plain-text way to open a TCP connection to a port and type into it.
Connection refused
The PC answered, but nothing is listening on that port.
