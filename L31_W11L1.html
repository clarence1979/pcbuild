10 minLearnteacher explains, you follow on screen

An installer is just an operating system small enough to run from a USB stick. You write the ISO to the stick (not copy; write), boot the stick with F12, and the installer copies the real OS onto your SSD.

Example 1. Copying the ISO file onto the stick in Explorer: the stick will not boot. It must be written with Rufus/Etcher/Ventoy so the stick has a boot sector and the files laid out properly.

Example 2. Picking the wrong install target erases the wrong drive. Identify by size and model: the 500 GB NVMe, not the 240 GB SATA with your data.

Example 3. Secure Boot on + unsigned installer = 'invalid signature'. Turn Secure Boot off in F2 for the install if that happens.
