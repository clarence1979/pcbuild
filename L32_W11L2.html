8 minLearnteacher explains, you follow on screen

Right after an install, the OS knows the basics. It may not know your graphics card's full features, your network card, or the latest security fixes. Drivers and updates fill those gaps. Then you set the names and accounts the lab expects, record the specs, and the PC is 'imaged'.

Example 1. Screen stuck at 1024×768 and sluggish: the graphics driver is missing.

Example 2. The network port shows 'cable unplugged' with a cable in: wrong or missing network driver.

Example 3. Windows says 'not activated' after a clean install on an OEM Dell: usually clears once online; the key lives in the firmware.

Words

Driver
Code that teaches the OS to use a specific piece of hardware.
Update
Fixes and security patches from the OS maker.
Activation
Proving the Windows licence; the Dell's key is stored in the firmware.
Image
A saved copy of a finished install that can be put back quickly.
