10 minLearnteacher explains, you follow on screen

A blank drive is like a notebook with no page numbers or contents page. Initialising chooses the table style (GPT). Partitioning draws the sections. Formatting writes the empty contents page (the file system). Only then can the OS put files on it.

Example 1. A 1 TB drive split into OS (200 GB) and Data (800 GB). Reinstalling Windows wipes the OS partition and leaves Data alone.

Example 2. A USB stick formatted exFAT works on Windows, Mac and Linux. NTFS is best for Windows system drives; ext4 for Linux.

Example 3. 'Quick format' takes seconds because it only rewrites the contents page. The old files are still physically there until overwritten, which is why recovery tools exist and why you wipe a drive properly before giving a PC away.

Words

Partition
A section of a disk the OS treats as a separate drive.
GPT / MBR
Two ways to write the partition table; GPT is the modern one used with UEFI.
File system
The index that turns raw space into folders and files: NTFS, exFAT, ext4.
Format
Writing a new empty file system onto a partition.
