A CPU does only one thing: it repeats a tiny loop, billions of times a second.

  1. Fetch the next instruction from RAM.
  2. Decode it: what is it asking for?
  3. Execute it: add, compare, move, jump.

Example 1 — clock speed. 3.4 GHz means 3.4 billion ticks a second. Roughly one small step per tick. A 4.0 GHz chip is not twice as fast as a 2.0 GHz one from a different generation, but inside one family, faster ticks = faster work.

Example 2 — cores. Four cores are four of these loops running at the same time. A game that only uses one core will not speed up with eight cores; a video export that uses all of them will.

Example 3 — cache. RAM is far away (in CPU time, a trip across town). Cache is a notepad on the desk. The CPU keeps the most-used data there so it rarely waits. More cache = fewer waits.

Your bench PC: Intel Core i5-7500 — 4 cores, 4 threads, 3.4 GHz base / 3.8 GHz boost, 6 MB cache, 65 W TDP, socket LGA1151. Some units may carry an i3 or i7; check yours.

Words

Core
One complete processing unit inside the CPU; four cores can run four jobs at once.
Clock speed
How many steps per second, measured in GHz (billions).
Cache
A small, very fast memory inside the CPU.
Thread
One stream of instructions.
TDP
Thermal design power: how much heat (in watts) the cooler must remove.
