14 minLearnteacher explains, you follow on screen

A PC decides for itself whether another address is 'local'. It ANDs its own address with the mask to get its network, does the same to the destination, and compares. Same network → talk directly through the switch (ARP for the MAC, send). Different → hand the packet to the default gateway, a router. No router in our lab means different networks simply cannot talk. That is the whole point of an isolated lab.

Example 1. 192.168.10.11 /24 and 192.168.10.42 /24: first 24 bits match (192.168.10). Same network.

Example 2. 192.168.10.11 /24 and 192.168.11.11 /24: third octet differs. Different network. No gateway → 'Destination unreachable'.

Example 3. 192.168.10.11 /16 and 192.168.11.11 /16: now only 16 bits are the network, so both are in 192.168.x.x. Same network. The mask, not the numbers, decides.

Words

Subnet mask
A pattern of 1s then 0s that says which part of the address is the network and which is the host.
/24
CIDR notation: the first 24 bits are the network; same as 255.255.255.0.
Host
The part of the address that identifies one PC within the network.
Default gateway
The router's address: where packets go when the destination is on a different network.
